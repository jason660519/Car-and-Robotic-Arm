1.2 描述你正在製作的系統 Describe the system you are making 已填寫 / Filled

原文（English original）：
"An closed loop mechatronics autonomous vehicle built around a Raspberry Pi that runs modular Python software (drivers, perception with OpenCV/ML, planner, and actuator interface) and communicates with a NeZha I2C motor/servo controller to drive DC motors and servos. It uses a camera and sensors for vision-guided object detection and obstacle avoidance."
中文翻譯（Chinese translation）：
這是一台以樹莓派（Raspberry Pi）為核心的閉環（closed-loop）機電一體化自動駕駛車輛。 樹莓派上運行著模組化的 Python 軟體（包括驅動程式、基於 OpenCV／機器學習的感知模組、規劃器， 以及執行器介面），並透過 NeZha I2C 馬達／舵機控制器與之通訊，來驅動直流馬達（DC motors）和舵機（servos）。 車輛使用攝影機與感測器進行視覺引導的目標偵測與障礙物迴避。
重點詞彙解釋 / Key terms：
  • Closed-loop（閉環）：系統透過感測器回饋持續校正動作，而不是「開環」地盲目執行指令。
  • Modular Python software（模組化軟體）：把驅動、感知、規劃、執行分成獨立模組，便於維護與測試。
  • OpenCV / ML（感知）：用電腦視覺與機器學習模型辨識影像中的物體。
  • Planner（規劃器）：根據感知結果決定車輛的下一步動作（例如轉向、加速、避障路徑）。
  • NeZha I2C controller：哪吒驅動板，透過 I2C 匯流排接收樹莓派的指令，輸出 PWM 控制直流馬達與舵機。
  • Vision-guided object detection & obstacle avoidance：以攝影機為主的視覺導向目標偵測與避障。
